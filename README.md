# Kogakufuro 🌀

**光学フロー(オプティカルフロー)を、あなたの端末だけで解析するWebアプリ。**
サーバーは一切使いません。動画・画像・カメラ映像は、あなたのブラウザの外に出ることはありません。

すべての計算は WebGL2 のフラグメントシェーダ上、つまり GPU 上で完結します。

## 特徴

- **完全クライアントサイド処理** — 動画/画像/Webカメラ映像を一切アップロードせず、ブラウザ内(WebGL2)だけで解析
- **ピラミッド型 Horn–Schunck 密光学フロー** をGPU上でフルスクラッチ実装(教科書通りの離散微分マスク + ヤコビ法による反復最小化 + 粗密ピラミッドによる大変位対応)
- **最大1000fpsのソース映像に対応** — 高速度カメラ動画の実フレームレートを指定し、コマ送りで1フレームずつ厳密に解析する「ステップ解析モード」を搭載
- 入力ソース3種: **動画ファイル / Webカメラ / 静止画2枚比較**
- 可視化: **方向カラーホイール / 速さヒートマップ / 元映像**、**矢印グリッド**、**流線パーティクル(ストリークライン)**、**分割表示・重ね合わせ表示**
- **ROI(解析範囲)指定** — キャンバス上をドラッグして解析範囲を絞り込み、高速化
- **計算解像度と出力解像度を分離** — 「処理解像度スケール」は内部の計算負荷だけを軽くし、画面表示・PNG/WebM書き出し・CSV/JSONのフローデータは常に元映像に近い解像度を維持
- **超高精度〜爆速まで無段階調整** — α(平滑化)・反復回数(最大500)・ピラミッド段数(最大10)・処理解像度スケール(2〜100%)を極端な範囲まで自由に調整可能。「爆速」「超高精度」を含む7種のプリセットを搭載
- **実寸キャリブレーション** — 基準ピクセル数と実距離を入力し、px/frame を実速度(cm/s等)に変換
- リアルタイム統計: 処理スループット(fps)、平均/最大の動きの大きさ、時系列スパークライン、速さのヒストグラム
- エクスポート: **PNGスナップショット / WebM録画 / フローデータCSV・JSON / 全フレーム一括解析(統計CSV)**
- 日本語 / English 切り替え、ダーク/ライトテーマ、キーボードショートカット、フルスクリーン対応
- ビルド不要 — `index.html` をブラウザで開くだけで動作(静的ファイルのみ)

## 使い方

```bash
# 依存関係なし。適当な静的サーバーで配信するか、index.html を直接開くだけ。
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

Webカメラを使う場合、ブラウザによっては `file://` から直接開くより
`http://localhost` 等から配信したほうが安定して動作します。

## 動作要件

- WebGL2 に対応したブラウザ(最新の Chrome / Edge / Firefox / Safari)
- `EXT_color_buffer_float` 拡張(高精度浮動小数点テクスチャへの描画。ほとんどのデスクトップGPUで利用可能)

対応していない環境では、起動時にエラーメッセージを表示します。

## アルゴリズムについて

1. 入力フレーム(動画/カメラ/静止画)を Canvas 2D で処理解像度にリサイズし、WebGLテクスチャへアップロード
2. フラグメントシェーダでグレースケール化
3. ボックスフィルタで複数解像度のピラミッドを構築(段数は調整可能)
4. 最も粗い解像度から Horn & Schunck の離散微分マスクで (Ix, Iy, It) を計算し、
   ヤコビ法による反復でエネルギー最小化を解く
5. 得られたフローを1段階細かい解像度へアップサンプリング(変位量を2倍)し、初期値として次段を解く
6. 元の解像度に到達するまで繰り返し、最終的な密光学フロー場を得る

全ステップがGPU上のテクスチャ間で完結するため、`readPixels` による同期読み出しは
「平均/最大の動きの大きさ」用の小さな縮小(リダクション)と、可視化用の
矢印/パーティクル用の小さなグリッド読み出しのみに限定されています。

## ファイル構成

```
index.html            画面構造
css/style.css          UIスタイル(ダーク/ライトテーマ対応)
js/gl-utils.js          WebGL2ヘルパー
js/shaders.js           GLSLシェーダ一式
js/optical-flow.js      ピラミッドHorn–Schunck GPU実装
js/visualization.js     フロー場の着色(方向ホイール/ヒートマップ/ブレンド)
js/overlay.js           矢印・パーティクル・スパークライン・ヒストグラム(2D Canvas)
js/video-source.js      動画/Webカメラ/画像の読み込みユーティリティ
js/i18n.js              日本語/English 辞書
js/app.js               メインコントローラ(状態管理・ループ・UI配線・エクスポート)
```

## プライバシー

このアプリはネットワーク通信を一切行いません(外部フォントやCDNへの依存もありません)。
読み込んだ動画・画像・カメラ映像は、あなたの端末のメモリ上でのみ処理され、
どこにも送信・保存されません。
